# Migration 026 — v3.15.0

## Summary

Adds a **governance audit trail** — a queryable, actor-attributed, tamper-evident record of the
governance events that previously vanished to stderr: gate blocks, gate bypasses/overrides
(`APPROVE ALL`, `SAVE … ACCEPT`, `/skip-icea`, `SKIP_FINDINGS_GATE`), approvals, and dismissals.
Events are written one-per-line to per-day/per-pid shards under `.claude/audit/*.jsonl`, each
stamped with all available identity signals (OS/AD login, git email, PAT-verified ADO
principal) plus an explicit `actor_confidence`. `/skip-icea` and `SKIP_FINDINGS_GATE` now
**require a justification**. Also fixes a pre-existing omission: `script-review-gate.cjs` was
deployed and wired but missing from the bootstrap `HOOK_FILES` list.

**Honest scope:** this captures *sanctioned* bypass verbs and *deterministic* gate hits with
best-effort attribution. It is not tamper-proof and does not catch an adversary who avoids the
keywords; integrity is tamper-*evident* only once `validate-audit.py` is wired into the pipeline
and the branch is protected.

## Change type

New hooks + settings wiring + one pre-commit behavior change (findings bypass now requires a
justification) + `.gitignore` managed-block addition. Applied by `/setup-sync`.

## Required action

Run `/setup-sync` (or `/dream-sync`) to deploy the new hooks, wire the `UserPromptSubmit` audit
hook, refresh `.hashes`, and add `.claude/session-context.json` to the ignore block. Then add
`python3 .claude/hooks/validate-audit.py` to the ADO pipeline (printed by setup-init/sync) and
keep the pipeline a required Build Validation — this is what makes the trail tamper-evident.

## Sync actions (idempotent — never overwrite developer content)

1. Deploy `audit-append.cjs`, `audit-prompt.cjs`, `validate-audit.py` (and the newly-listed
   `script-review-gate.cjs`) to `.claude/hooks/`; recompute `.hashes`.
2. Wire `UserPromptSubmit → node .claude/hooks/audit-prompt.cjs` in `.claude/settings.json`.
3. Add `.claude/session-context.json` to the managed ignore block (the `.claude/audit/` shards
   are intentionally NOT ignored — they must be committed for the append-only check).
4. Re-print the pipeline instructions including `validate-audit.py`.

## New files (deployed to `.claude/hooks/`)

- `audit-append.cjs` — shared append helper (module `appendEvent()` + CLI). Resolves identity,
  grades `actor_confidence`, secret-scans `detail`, appends to `.claude/audit/<date>-<pid>.jsonl`.
- `audit-prompt.cjs` — `UserPromptSubmit` hook. Records the governance verbs (intent signals)
  and enforces the `/skip-icea` justification ask.
- `validate-audit.py` — CI validator: per-shard JSON schema + append-only vs the base ref
  (degrades to schema-only under squash-merge).

## Hook / skill / config changes

- `scripts/setup-init-bootstrap.cjs`: `HOOK_FILES` += `script-review-gate.cjs` (omission fix),
  `audit-append.cjs`, `audit-prompt.cjs`, `validate-audit.py`; `stepWireSettings` adds the
  `audit-prompt` `UserPromptSubmit` entry; pipeline print adds `validate-audit.py`;
  `GITIGNORE_BASE` += `.claude/session-context.json`.
- `commands/gitignore-sync.md`: BASE arrays += `.claude/session-context.json` (sync with above).
- Guard hooks (`icea-floor`, `check-settings-secrets`, `script-review-gate`,
  `context-budget-tech-write`, `findings-gate-precommit`) now append a `gate.block` event on
  block via the shared helper (best-effort — never blocks the gate).
- `findings-gate-precommit` (`.cjs` + `.sh`): `SKIP_FINDINGS_GATE=1` now **requires**
  `FINDINGS_GATE_JUSTIFICATION="reason"` (hard-fail if absent) and logs a `gate.bypass` event.
- `commands/session-start.md`: new Step 1b resolves and caches identity (7-day) into
  `.claude/session-context.json` (AD UPN via `whoami /upn`; ADO principal via the profile API
  when a PAT is present). Best-effort, non-blocking.
- `skills/setup-status/SKILL.md`: verifies the audit hooks and adds an audit-liveness self-check
  (amber when wired-but-silent or not wired).
