REC-P04 — Break long sessions into focused sub-sessions (<20 turns)

Finding: 9 of 10 sessions exceed 20 turns. The ICEA workflow session ran 667 turns. Sessions 755e3591 (222 turns) and 19963629 (272 turns) hit context limits, triggering expensive full-context re-send on resume. The cost-index for the ICEA session (11.7M) reflects severe context accumulation.
Each sub-session should have a single goal. Suggested splits:
  • Bug investigation: (1) reproduce + RCA, (2) implement fix, (3) test + checkin — three sessions
  • ICEA cycle: (1) plan + SAVE PLAN, (2) ICEA + SAVE ICEA, (3) IMPLEMENT + checkin — three sessions
  • Setup tasks: architect, graph-sync, and dream should each be their own focused session
Use /session-start at the beginning of each new sub-session to reload memory cheaply.
