# How to Generate the AI in SDLC Presentation

## Quick Start (3 steps)

### Step 1: Clone or download the repository
```bash
git clone https://github.com/vickysrawat/AI-Assisted-development.git
cd AI-Assisted-development
```

### Step 2: Run the script
```bash
python create_pptx.py
```

### Step 3: Find your file
Look for: **`AI_in_SDLC_Presentation.pptx`** in the repository root
